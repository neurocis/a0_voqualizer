- Tag command for repository maintainers:

```bash
git tag -a v0.1.0 -m "a0_voqualizer v0.1.0"

```

This artifact records the tag target and release checklist in-repo. If the
working checkout is not a git repository or tag push credentials are not
available in normal pytest, creating/pushing the tag is intentionally left to the
release owner. The release validation remains deterministic and offline.
